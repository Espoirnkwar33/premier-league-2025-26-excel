# Analyse de la Premier League 2025-26 (Excel)

## Objectif
Reconstituer le classement final de la Premier League 2025-26 à partir des résultats bruts de chaque match, puis construire un dashboard interactif.

## Source des données
[football-data.co.uk](https://www.football-data.co.uk) - 380 matchs de la saison 2025-26.

## Contenu du fichier
- `season-2526` : données brutes des matchs + colonnes calculées (points par match)
- `classement` : classement final construit avec NB.SI() et SOMME.SI()
- `TCD` : tableaux croisés dynamiques (points domicile/extérieur, buts marqués/encaissés)
- `Dashboard` : dashboard interactif avec segment filtrant par équipe

## Résultats
- 🏆 Champion : Arsenal, 85 points

## Compétences travaillées
Nettoyage de données, tableaux Excel, formules conditionnelles, tableaux croisés dynamiques, segments, dashboard interactif.
